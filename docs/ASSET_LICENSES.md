# Asset licences

Every asset in the game, where it comes from, and under what terms. Update this whenever an asset is added or replaced (CLAUDE.md rule).

## Speech

| What | Source | Licence | Notes |
|---|---|---|---|
| Spoken sentences, `src/speech/audio/sv/*.mp3` | Generated by us with `npm run speech` | Ours | Text from `src/content`; list in `src/speech/audio/sv/clips.json` |
| Voice model `sv_SE-alma-medium` ("Alma", female) | [yeagersthlm/piper-voice-sv-alma](https://huggingface.co/yeagersthlm/piper-voice-sv-alma) via [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices) | CC BY 4.0, following the NST Swedish TTS dataset (Språkbanken, National Library of Norway) | Used at build time only. **Attribution required**: shown on the start screen (`src/content/credits.ts`) |
| Text-to-speech engine Piper (`piper-tts` 1.8.0) | [PyPI](https://pypi.org/project/piper-tts/) | GPL-3.0-or-later | Build tool only: runs on the developer's machine, is not shipped or linked; its output audio is not covered by the GPL |
| `src/speech/audio/silence.mp3` | Generated with ffmpeg | Ours | 0.1 s of silence used to enable audio on iPad |
